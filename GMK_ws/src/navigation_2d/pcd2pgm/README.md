# pcd2pgm

将三维点云文件（`.pcd`）转换为 ROS2 `nav2_map_server` 标准格式的二维占用栅格地图。

## 工作原理

借助 **octomap C++ API** 完成三维体素化与二维投影，与原 `octomap_server` 产生相同的体素语义：

```
PCD 文件
  → PCL 高度滤波（保留指定 z 范围的切片）
  → 可选：体素降采样 / 半径离群点去除
  → octomap::OcTree 三维体素化（去重 + 占用概率）
  → XY 平面投影（occupied 叶节点 → 黑色栅格）
  → map.pgm  +  map.yaml
```

**PGM 像素值约定**（与 `nav2_map_server` / `map_saver` 一致，`negate: 0`）：

| 像素值 | 含义 |
|--------|------|
| 0      | 占用（黑色）|
| 254    | 自由（白色）|
| 205    | 未知（灰色）|

## 依赖安装

```bash
# octomap C++ 库
sudo apt install liboctomap-dev

# PCL
sudo apt install libpcl-dev

# ROS2 相关（Humble）
sudo apt install ros-humble-pcl-ros
```

## 构建

```bash
cd ~/nav_ws
colcon build --packages-select pcd2pgm
source install/setup.bash
```

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `pcd_file` | **必填** | 输入 PCD 文件的绝对路径 |
| `output_dir` | `.` | 输出目录（自动创建） |
| `map_name` | `map` | 输出文件名前缀（生成 `<map_name>.pgm` 和 `<map_name>.yaml`） |
| `resolution` | `0.05` | 体素/栅格分辨率（米/像素），同时决定 octomap 的分辨率 |
| `minh` | `-0.3` | 高度切片下限（米），过低的点（地面）不纳入地图 |
| `maxh` | `1.5` | 高度切片上限（米），过高的点（天花板）不纳入地图 |
| `padding` | `1.0` | 地图四周向外扩展的留白（米） |
| `enable_voxel_filter` | `false` | 是否在插入 octomap 前做体素降采样（大点云时可加速） |
| `voxel_leaf_size` | `0.05` | 预降采样的体素大小（米） |
| `enable_radius_filter` | `false` | 是否启用半径离群点去除 |
| `radius_filter` | `0.3` | 半径离群点搜索半径（米） |
| `min_neighbors` | `5` | 半径内最小邻居点数，低于此值视为离群点 |
| `default_cell` | `free` | 非占用格的默认值：`free`=254（白色）/ `unknown`=205（灰色） |
| `occupied_thresh` | `0.65` | 写入 YAML 的占用概率阈值（供 map_server 读取） |
| `free_thresh` | `0.196` | 写入 YAML 的自由概率阈值（供 map_server 读取） |

## 使用方法

### ros2 launch（推荐）

```bash
ros2 launch pcd2pgm pcd2pgm.launch.py \
    pcd_file:=/path/to/your_map.pcd \
    output_dir:=/path/to/output \
    map_name:=map \
    resolution:=0.05 \
    minh:=-0.3 \
    maxh:=1.5
```

### ros2 run（直接运行）

```bash
ros2 run pcd2pgm pcd2pgm_node \
    --ros-args \
    -p pcd_file:=/path/to/your_map.pcd \
    -p output_dir:=/path/to/output \
    -p resolution:=0.05 \
    -p minh:=-0.3 \
    -p maxh:=1.5
```

### 常见场景示例

```bash
# 室内地图，调整高度切片为传感器扫描高度
ros2 launch pcd2pgm pcd2pgm.launch.py \
    pcd_file:=/maps/indoor.pcd \
    output_dir:=/maps/output \
    minh:=0.1 maxh:=1.2 \
    resolution:=0.05

# 大规模点云，启用预降采样加速处理
ros2 launch pcd2pgm pcd2pgm.launch.py \
    pcd_file:=/maps/large_outdoor.pcd \
    output_dir:=/maps/output \
    enable_voxel_filter:=true voxel_leaf_size:=0.05 \
    resolution:=0.1

# 保守模式：未知区域显示为灰色
ros2 launch pcd2pgm pcd2pgm.launch.py \
    pcd_file:=/maps/map.pcd \
    output_dir:=/maps/output \
    default_cell:=unknown
```

## 输出文件格式

### map.pgm

标准 PGM（P5 二进制）灰度图，可直接用于 `nav2_map_server`：

```
P5
# generated by pcd2pgm (octomap)
<width> <height>
255
<binary pixel data>
```

### map.yaml

```yaml
image: map.pgm
resolution: 0.050000
origin: [-12.500000, -8.200000, 0.0]
negate: 0
occupied_thresh: 0.65
free_thresh: 0.196
mode: trinary
```

### 加载地图

```bash
# nav2_map_server
ros2 run nav2_map_server map_server --ros-args -p yaml_filename:=/path/to/map.yaml
```
