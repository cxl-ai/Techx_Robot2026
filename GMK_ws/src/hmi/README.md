# R2 HMI - ROBOCON 2026 战术指挥系统

## 环境要求

- Python 3.8+
- PySide6

```bash
pip install PySide6
```

## 运行

```bash
cd r2_hmi_ws/src/r2_hmi_app
python main.py
```

没有 ROS2 环境时自动切换为 **Mock 模式**（模拟后端），所有功能可正常操作和测试。

## 操作流程

### 阶段 0：选择阵营

启动后选择 **红方** 或 **蓝方**，系统自动进入标定页。

### 阶段 1：梅林区标定（12 宫格）

在 4x3 网格上标记场地状态：

| 画笔 | 颜色 | 含义 |
|------|------|------|
| 真 R2 KFS | 绿色 | R2 目标 KFS，可通过 |
| 假 KFS | 红色 | 不可通行（阻挡） |
| R1 KFS | 蓝色 | R1 KFS，可通过（安全绕行） |

- 点击格子切换标记，再次点击取消
- 底部 **红色按钮** 一键清除全部标记
- 点击 **下发并锁定** 确认标定，进入赛中看板

**A* 路径规划：** 标记假 KFS 后，系统自动计算从入口到出口的最短路径，路径格子显示金色发光边框。

### 阶段 2：赛中看板

三张任务卡片：

| 卡片 | 功能 |
|------|------|
| 武馆区 | 点击执行任务 |
| 梅林区 | 修改标定 / 执行任务 |
| 对抗区 | 展开 3x3 九宫格，多选目标后执行 |

### 对抗区九宫格

- 点击格子选中/取消目标（支持多选）
- 底部 **执行任务** 下发当前选择
- **清除** 按钮清空所有选择
- 执行后自动回到卡片界面，再次打开保留之前选择

### 急停

右下角红色急停按钮，点击后锁死所有任务执行。

## 项目结构

```
r2_hmi_ws/src/r2_hmi_app/
├── main.py                 # 应用入口
├── frontend/
│   ├── Main.qml            # 主窗口框架
│   ├── BootPage.qml        # 阵营选择页
│   ├── CalibrationPage.qml # 梅林区标定页（含 A* 路径规划）
│   ├── DashboardPage.qml   # 赛中看板
│   └── components/
│       ├── StageCard.qml   # 赛段卡片
│       ├── CombatGrid.qml  # 对抗区 3x3 九宫格
│       └── StyleConstants.qml  # 全局颜色常量
└── backend/
    ├── ros_worker.py       # ROS2 后台线程（Mock 兼容）
    └── ros_compat.py       # ROS2 / Mock 兼容层
```
